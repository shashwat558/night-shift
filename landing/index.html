The overnight problem

Agents made coding fast.
They didn’t make trust fast.

By morning, five pull requests can look like five new decisions. Night Shift makes the evidence arrive with the work.

Claims are not receipts

“Tests pass” is cheap. Night Shift overlays the worker’s claim with the actual diff, actual test exit, raw log tail, and measured budget.

Parallel work collides

Workers declare file claims before coding. Shared paths trigger a visible negotiation and an agreed landing order.

Approval goes stale

Every decision is bound to the reviewed commit. Push again and the evidence fingerprint changes—so the old approval no longer counts.

One goal in. A controlled night out.

Five moves from message
to morning clarity.

The agents get autonomy inside a narrow lane. Everything consequential becomes visible to the team.

  1. 01

    Set tonight’s goal

    Post one plain-language goal in Mattermost, Slack, Discord, Teams, or Telegram. Switch carries it into the shared room.

    tonight: fix pagination
  2. 02

    Scope the slips

    The night lead creates bounded tasks with allowed files, acceptance criteria, and a wall-clock budget.

    files_allowed: [routes/pets.js]
  3. 03

    Let workers build

    OpenCode, Codex, or Claude works on isolated branches. The supervisor kills overruns and continues the night.

    WORKER_PROVIDER=codex
  4. 04

    Review machine truth

    Receipts, live CI, repository policy, reviewer findings, and the head SHA become one decision card.

    @shift-supervisor inspect B-…
  5. 05

    Wake up to the handoff

    At 9 AM, a deterministic report lists merges, holds, rollbacks, blocks, trust figures, and the next recommendation.

    shift report please

Trust control tower

Green tests are necessary.
Not sufficient.

Night Shift reviews four independent facts at approval time. An agent cannot talk its way around a blocked path, missing receipt, red CI check, or changed commit.
