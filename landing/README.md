# Night Shift landing page

This is a dependency-free static presentation of Night Shift. Its interface
examples explain real product behavior but do not claim to show a specific
live run.

Preview it from the repository root:

```sh
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173/landing/`.

The page is responsive, keyboard navigable, theme-aware, and respects
`prefers-reduced-motion`. It has no build step.
